# نقشة طين | Naqshat Teen - متجر الفخار اليدوي

متجر إلكتروني متخصص في المنتجات الفخارية والخزفية اليدوية، مصمم بتقنيات حديثة ويعكس جمال التراث والأصالة.

## 🎨 التصميم والهوية البصرية

### الألوان المستخدمة:
- **اللون الأساسي**: بني ترابي (#8B4513) - مستوحى من لون الطين الطبيعي
- **اللون الثانوي**: بيج فاتح (#F5E6D3) - يعكس دفء الفخار
- **لون التمييز**: ذهبي نحاسي (#CD853F) - يضيف لمسة فخامة
- **الخلفية**: كريمي دافئ (#FFF8E7) - مريح للعين

### العملة:
- **الدينار الأردني (د.أ)** - جميع الأسعار معروضة بالدينار الأردني
- نطاق الأسعار: 10 - 30 دينار أردني حسب الحجم والوقت

### الموقع:
- **الأردن - الكرك**

### الخطوط:
- استخدام خطوط عربية واضحة وعصرية تناسب الهوية التراثية

##  هيكل المشروع

```
src/
├── app/
│   ├── page.tsx              # الصفحة الرئيسية
│   ├── layout.tsx            # التخطيط الأساسي (RTL للعربية)
│   ├── globals.css           # التنسيقات العامة والألوان
│   ├── about/                # صفحة "عن المتجر"
│   ├── cart/                 # صفحة سلة التسوق
│   ├── categories/           # صفحة التصنيفات
│   ├── contact/              # صفحة التواصل
│   ├── products/             # صفحة المنتجات وتفاصيل المنتج
│   └── api/                  # واجهات برمجة التطبيقات
│       ├── categories/       # API لجلب التصنيفات
│       ├── products/         # API لجلب المنتجات
│       ├── seed/             # API لملء قاعدة البيانات
│       └── health/           # API لفحص الصحة
├── components/
│   ├── Header.tsx            # مكون الرأس والقائمة
│   └── Footer.tsx            # مكون التذييل
└── db/
    ├── index.ts              # اتصال قاعدة البيانات
    ├── schema.ts             # مخطط قاعدة البيانات
    └── seed.ts               # بيانات تجريبية
```

## 🗄️ قاعدة البيانات

### الجداول:
1. **categories** - تصنيفات المنتجات
2. **products** - المنتجات
3. **cart_items** - عناصر سلة التسوق
4. **orders** - الطلبات
5. **order_items** - عناصر الطلبات

### ملء قاعدة البيانات:
```bash
# تشغيل التهيئة الأولية
POST /api/seed
```

## 🛍️ أقسام المتجر

### 1. الصفحة الرئيسية
- قسم البطل (Hero) مع شعار المتجر وصورة الخلفية
- مميزات المتجر (صنع يدوي، مواد طبيعية، إلخ)
- تصنيفات المنتجات
- منتجات مميزة
- نبذة عن المتجر
- نموذج الاشتراك في النشرة البريدية

### 2. صفحة المنتجات
- عرض جميع المنتجات في شبكة متجاوبة
- فلترة حسب التصنيف
- بحث عن المنتجات
- بطاقات منتجات مع الأسعار والحالة

### 3. صفحة المنتج
- صور المنتج
- وصف تفصيلي
- المواصفات الكاملة
- طريقة العناية بالفخار
- منتجات ذات صلة
- التقييمات

### 4. صفحة التصنيفات
- عرض جميع التصنيفات
- كل تصنيف مع وصف وعدد المنتجات

### 5. صفحة "عن المتجر"
- قصة اسم "نقشة طين"
- قيم المتجر
- فريق العمل
- دعوة للتسوق

### 6. صفحة التواصل
- نموذج اتصال
- معلومات التواصل
- الأسئلة الشائعة

### 7. سلة التسوق
- عرض المنتجات المضافة
- تعديل الكميات
- حساب المجموع والشحن
- إتمام الطلب
